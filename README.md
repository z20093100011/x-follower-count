# X 粉丝数显示

## 功能

Chrome Manifest V3 扩展，在 x.com / twitter.com（含 mobile 子域）的推文用户名、用户列表、个人资料标题和悬浮用户卡片中，为已知的 @账号添加粉丝数标签，例如 `粉丝 17.4万`、`粉丝 1,574`、`粉丝 423`。标签优先放在 @账号前的同一横行；侧栏或拥挤布局中紧跟 @账号，避免单独换行。采用浅蓝底、蓝色文字的圆角胶囊样式，支持 X 的深色模式（纯黑和暗蓝背景）。悬停标签时显示自定义详情卡：粉丝和关注的精确数量、粉丝/关注比、推文数、注册年月及账号年龄、关注关系（仅显示已知字段）。粉丝标签后会显示紫色「互关」或「关注了你」关系标签。标签拦截鼠标／指针移动事件，抑制 X 自带的个人资料悬浮卡；点击标签不会跳转。

## 原理

不调 API，读取网页自身的 GraphQL 响应及 `/i/api/` JSON 响应。在 MAIN 世界包装 fetch 和 XMLHttpRequest，fetch 只读取响应副本；从返回数据中提取账号与粉丝数，通过页面内消息交给 ISOLATED 世界的显示脚本。显示脚本观察 DOM 变化，按需添加或更新标签。

粉丝数优先读取 relationship_counts.followers，再读取 legacy.followers_count、followers_count。同一响应重复出现的账号按出现顺序合并，后面的有效值覆盖或补全字段，空值不抹去已知数据；后续响应覆盖旧值（包括粉丝数下降）。缓存仅在内存中保留约 5000 个账号；页面内握手补发显示脚本启动前已捕获的数据。

## 安装步骤

1. 下载并解压此项目。
2. 打开 `chrome://extensions`。
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择包含 `manifest.json` 的文件夹。
6. 刷新 x.com（或 twitter.com）页面。

无需安装 npm 依赖或构建。

## 设置面板

先点击 Chrome 工具栏的拼图图标，将「X 粉丝数显示」固定到工具栏，再点击扩展图标打开设置面板。所有开关更改即时生效，无需刷新页面。

- **显示粉丝数（总开关）**：默认开启；关闭后移除所有粉丝数及关系标签，其他设置行变灰且不可操作。页面数据仍在内存中更新，再开启即可恢复已知账号的标签。
- **关系标签**：默认开启，显示「互关 / 关注了你」胶囊标签。
- **悬停详情卡**：默认开启，悬停粉丝标签时显示精确数量及账号详情。
- **粉丝量分级配色**：默认关闭，开启后按粉丝数量改变标签颜色。
- **调试条**：默认关闭，在左下角显示响应、用户和徽标计数。

颜色分档：不足 1,000 为灰色，1,000–9,999 为蓝色，1万–不足 10万为绿色，10万–不足 100万为橙色，100万及以上为粉橙渐变；均有深色模式配色。关闭分档时保留原来的蓝色标签。

左下角调试条显示 `XFC 响应 N · 用户 N · 徽标 N`：响应为成功解析的相关 JSON 响应累计数（含未找到用户的响应），用户为当前内存缓存中的账号数，徽标为当前文档中的标签组数量。刷新页面后重新统计。

扩展包含 16、32、48、128 像素的蓝底白色人物图标，点击工具栏图标即可打开设置面板。图标可用 Pillow 重新生成：`python3 tools/make_icons.py`。

## 隐私说明

扩展本身不联网、不主动请求任何 API、不上传浏览数据、不加载远程代码。仅使用 `storage` 权限，将五个布尔开关保存在 `chrome.storage.sync` 的唯一键 `xfcSettings` 下；若开启 Chrome 同步，设置会随用户的 Chrome 账号同步。不会保存浏览数据、账号或粉丝数。只处理当前网页已有的响应，临时缓存随刷新或关闭页面清空。manifest 不声明 `host_permissions`，仅在四个指定站点匹配内容脚本。

## 已知限制

- X 改字段名或 DOM 结构会导致功能失效。
- 只能显示页面加载过的用户数据；DOM 里出现但没有请求过对应粉丝数据的用户不显示。
- 首次加载时，脚本安装前已经发出的请求可能抓不到，需刷新页面。
- 数值来自网页响应，不保证实时更新；没有粉丝数字段的响应无法补全。
- 此项目包含自动化数据解析测试，实际页面效果仍需在 Chrome 加载扩展后验证。

## 运行测试

安装支持 `node:test` 的 Node.js 后运行（无需 npm install）：

```sh
node --test test/walker.test.js test/config.test.js test/manifest.test.js
# 或
npm test
```

## 文件说明

- `manifest.json`：扩展声明、工具栏入口及唯一的 storage 权限。
- `src/config.js`：默认开关、设置规范化与同步订阅。
- `src/content.js`：标签、详情卡及实时设置应用。
- `src/inject.js`、`src/walker.js`：读取页面已有响应并解析用户数据。
- `popup/popup.html`、`popup/popup.css`、`popup/popup.js`：中文设置面板。
- `test/`：数据解析、配置同步和 manifest 测试。
- `icons/`、`tools/make_icons.py`：扩展图标与生成脚本。
